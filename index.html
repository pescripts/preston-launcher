A clean, fast launcher for Minecraft: Java Edition

Preston Launcher (Preston Client) is a free desktop launcher for Windows. Sign in with your Microsoft account, pick a version and play — with performance mods, HUD modules, emotes and cosmetics.

Private beta — public release coming soon

Features

Official game files

Minecraft is downloaded directly from Mojang's official servers. We never redistribute any game file.

Microsoft sign-in

Players sign in with their own Microsoft account to play the copy of Minecraft: Java Edition they own.

Performance

Optional Fabric profiles with well-known open-source performance mods (Sodium, Lithium…).

Preston Core mod

Our own mod: HUD modules, minimap, emotes and original cosmetics designed by our team.

Versions 1.20 to 26

Ready-made profiles for several Minecraft versions, each in its own game folder.

Free

The launcher is free. No account data is ever sold or shared.

How the Microsoft sign-in works

The launcher uses the standard Microsoft → Xbox Live → Minecraft sign-in, only to check that the player owns Minecraft: Java Edition and to get their Minecraft profile (username, UUID, skin) so the game can start and join online servers. Sign-in tokens stay on the player's computer, encrypted by the operating system, and are never sent to our servers or to anyone else. See the privacy policy.
